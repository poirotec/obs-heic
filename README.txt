OBS HEIC Drag & Drop Plugin  バージョン 1.1.0
============================================================

【このソフトについて】

Windows版OBS StudioへHEIC/HEIF画像をドラッグ＆ドロップで
取り込めるようにするプラグインです。

iPhoneで撮影した、タイル分割・回転情報・HDRゲインマップを含む
HEIC画像にも対応しています。画像はパソコン内で処理され、外部へ
送信されません。


【動作環境】

対応OS       : Windows 10 / Windows 11（64ビット版）
対応OBS      : OBS Studio 31以降（64ビット版）
対応ファイル : .heic / .heif / .hif
必要な権限   : インストール時のみ管理者権限が必要
追加ソフト   : 不要（必要なデコーダーを同梱しています）

32ビット版Windows、macOS、Linuxには対応していません。
Microsoft Storeの「HEIF画像拡張機能」は不要です。

ダウンロード・更新情報:
https://github.com/poirotec/obs-heic/releases


【インストール方法】

1. OBS Studioを終了します。
2. 「OBS-HEIC-Plugin-Setup-1.1.0.exe」をダブルクリックします。
3. ユーザーアカウント制御が表示されたら「はい」を選択します。
4. 画面の案内に従ってインストールします。
5. OBS Studioを起動します。

標準の場所へインストールされたOBS Studioが見つからない場合、
セットアップは中止されます。ポータブル版OBSを使用している場合は、
配布ZIP内の「obs-heic」フォルダーをOBSのプラグインフォルダーへ
手動でコピーしてください。


【使い方】

・エクスプローラーからHEIC画像をOBSのプレビュー画面へドロップします。
・「ソース」に「HEIC画像」として追加されます。
・複数のHEICをまとめてドロップできます。
・PNGやJPEGなど、OBS標準対応ファイルとの混在ドロップも可能です。

ソース欄の「+」から「HEIC画像」を選び、ファイルを指定することも
できます。


【アンインストール方法】

1. OBS Studioを終了します。
2. Windowsの「設定」→「アプリ」→「インストールされているアプリ」を
   開きます。
3. 「OBS HEIC Drag & Drop Plugin」を選び、アンインストールします。

アンインストール後、シーンに残っている「HEIC画像」ソースは読み込めなく
なります。再インストールすると再び読み込めます。


【うまく動かない場合】

■ HEICをドロップしても追加されない
  ・OBSを再起動してください。
  ・OBSのセーフモードではなく、通常モードで起動してください。
  ・OBS 31以降の64ビット版であることを確認してください。

■ 画像が表示されない
  ・ファイルが他の画像アプリで開けるか確認してください。
  ・ソースのプロパティを開き、ファイルを選び直してください。
  ・OBSの「ヘルプ」→「ログファイル」から現在のログを確認してください。

■ Windows SmartScreenが表示される
  この配布物にはコード署名が付いていません。配布ZIPに含まれる
  SHA256SUMS.txtのハッシュと一致することを確認してください。
  入手元が不明なファイルは実行しないでください。


【制限事項】

・HEICの主画像を静止画として表示します。
・Live Photosの動画部分や画像シーケンスは再生しません。
・元ファイルを書き換えた場合は、ソースのプロパティで選び直してください。
